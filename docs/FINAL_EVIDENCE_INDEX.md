## Recommended order for a final demo or defence
1. Start with architecture and stack readiness.
2. Show real-log validation as operational proof.
3. Show alerts, dashboard workflow, and human feedback.
4. Show retraining evidence and MLflow comparison logic.
5. Show explainability (SHAP, LIME, counterfactuals when available).
6. Close with monitoring, CI/CD, migrations, and throughput evidence.
